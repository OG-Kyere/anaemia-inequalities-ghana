# Socioeconomic and Geographic Inequalities in Anaemia Among Women of Reproductive Age in Ghana

This repository contains the reproducible workflow for a biostatistics study of socioeconomic and geographic inequalities in anaemia among women aged 15–49 years in Ghana.

## Study aim

The project will quantify socioeconomic inequality in anaemia, identify factors contributing to observed disparities, and assess whether anaemia varies across geographic and community contexts after accounting for individual-level characteristics.

## Data source

The analysis will use the 2022 Ghana Demographic and Health Survey (GDHS).

> **Important:** DHS microdata are restricted-use data and will **not** be uploaded to this repository. Users who wish to reproduce the analysis must request access directly from The DHS Program.

## Planned analyses

- Survey-weighted prevalence estimation
- Socioeconomic inequality measurement using concentration indices
- Decomposition of wealth-related inequality
- Multilevel regression for individual- and community-level variation
- Geographic and subgroup analyses
- Sensitivity analyses

## Repository structure

```
data/        Data-access instructions only; no DHS microdata
docs/        Study protocol and statistical analysis plan
src/         Analysis scripts
results/     Generated tables, figures, and model outputs
manuscript/  Manuscript and supplementary material
```
