# Data Access

This project uses restricted-use microdata from the **2022 Ghana Demographic and Health Survey (GDHS)**.

The raw DHS files must not be committed to this repository.

## Required file

The primary analysis will use the **Individual Recode (IR)** file for Ghana 2022.

## Reproduction

1. Request access to the Ghana 2022 DHS from The DHS Program.
2. Download the Individual Recode file after approval.
3. Store it locally under:

```
data/raw/
```

The `data/raw/` directory is ignored by Git and must remain private.

## Data governance

All analysis must comply with The DHS Program's terms of use. No attempt should be made to identify participants, and no restricted microdata should be redistributed.
