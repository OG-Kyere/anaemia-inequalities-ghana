# Data Access

This project uses restricted microdata from the **2022 Ghana Demographic and Health Survey (GDHS)**. The raw files are not stored in this repository.

## Required file

The main analysis uses the Ghana 2022 **Individual Recode (IR)** file.

## Reproducing the analysis

1. Request access to the Ghana 2022 DHS through The DHS Program.
2. After approval, download the Individual Recode file.
3. Keep the file locally under:

```text
data/raw/
```

The `data/raw/` directory is ignored by Git and should remain private.

## Data governance

Use of the dataset must follow The DHS Program's terms of use. Restricted microdata should not be redistributed, and no attempt should be made to identify individual participants.
